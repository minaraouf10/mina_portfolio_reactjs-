# Mina Raouf — Portfolio (React)

Personal portfolio site built with **React + Vite**, ported from the Flutter portfolio at `mina_portfolio`.

## Sections

- Hero / About
- Skills
- Selected work (project galleries)
- Experience
- Education
- Contact

## Content & assets

All copy lives in `src/data/portfolioData.js`.  
Images, icons, and CV are under `public/assets/` (copied from the Flutter project).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Theme

Light/dark mode follows system preference on first visit, then remembers the toggle in `localStorage`.
